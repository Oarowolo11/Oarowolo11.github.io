Abstract: Time domain simulation (TDS) is an important tool for assessing power system security under various disturbances. However, its computational cost limits the number of disturbances that can be assessed. The need for fast assessment of numerous disturbances has increased with the rapid integration of renewable energy sources. Machine learning (ML) methods have been explored to accelerate power system TDS, but these methods are studied in interpolation scenarios, where they predict outputs for inputs within the training data distribution. This work uses a state-of-the-art ML model to explore the extrapolation behaviour of ML models for TDS. First, we highlight the importance of ML models' extrapolation capacity for fast assessment of numerous diverse disturbances. Next, we demonstrate that extrapolation for discrete disturbances is more challenging than for continuous disturbances. Subsequently, we investigate how transfer learning (TL) may be used to improve the performance of ML models in TDS extrapolation scenarios. Finally, we outline the limitations of TL for power system TDS and suggest alternative approaches for developing ML models with better extrapolation performance in TDS applications.
